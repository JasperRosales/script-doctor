# Usage

## Quick scan

1. Add a Gemini API key in **Settings**, or choose **Try a sample result** to explore without a key.
2. On **Scan**, take a photo or choose one from the gallery. Preview or replace the image.
3. Select **Decode** and wait for the result; cancellation is available while processing.
4. Review the original alongside the result, and confirm the prescription with the prescriber or a licensed pharmacist. Open **History** to revisit a saved scan.

The sample uses fictional data and is not saved. Real scans require internet access and are sent to Google. See the [User guide](user-guide.md) for screen details.

## Troubleshooting



| Symptom | Check |
| --- | --- |
| Key missing or rejected | Save a nonblank key in Settings; check its validity and model access. |
| Rate limit or quota error | Check the provider account and quota; retry later. |
| Network or server error | Check connectivity and provider availability; retry. |
| Image cannot be read / no camera app | Select another image or install/use an available camera app. |
| Response incomplete or malformed | Retry with a clear, tightly framed photo; check model/API compatibility if persistent. |
| Gradle or SDK error | Confirm JDK 17, Android SDK API 35, SDK path, and dependency access. |
